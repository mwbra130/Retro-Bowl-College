# Retro Bowl College

Patches for **Retro Bowl College** (`com.newstargames.retrobowlcollege`, v1.1.2).

## 🩹 Patches

### Unlock premium
Unlocks the full version of the game by reporting a synthetic purchased entitlement to the game's purchase check. No real purchase is made.

## 📲 Use

1. Add `https://github.com/mwbra130/Retro-Bowl-College` as a source in Morphe Manager.
2. Select the Retro Bowl College APK and the **Unlock premium** patch, then patch.
3. Uninstall the original game first — patched builds are signed with a different key and won't install over it — then install the patched APK.

Patch source: [`../patches/src/main/kotlin/app/zdrgon/patches/retrobowlcollege/`](../patches/src/main/kotlin/app/zdrgon/patches/retrobowlcollege/)
